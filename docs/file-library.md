# 文件库

侧栏「文件库」先展示小说卡片和独立的共享资料入口。进入小说后再选择十个资料分区；上传归属当前小说，不需要逐次选所属作品。从作品内进入时默认本书，返回和刷新记住资料位置。旧共享资料保留原归属，可用「管理」手动移动到指定小说。

分区工作台左侧切换分区、文件夹与文件，右侧默认打开当前目录第一份文件；空目录直接展示上传区。左侧常驻上传按钮，也支持拖入文件。每次最多 100 个文件，单文件最大 20 MB；同名文件分别保留。参考书区的「书籍资料夹」按本计数，普通文件夹与附件不计为书。

TXT/Markdown 读取 UTF-8；DOCX 使用 Mammoth、PDF 使用 PDF.js 提取文本。扫描 PDF 不执行 OCR，旧 DOC 与其他格式保留原件。解析失败显示原因，原件仍可下载。PNG/JPEG/GIF/WebP 按内容签名预览。资料编辑区读取完整文本；只读正文接口仍按 20,000 字分页，正文不截掉。全文搜索跨当前小说当前分区的各目录，列表每页 100 个文件。作品概况显示真实章节、角色、设定和画布元素数，不推算剧情完成比例。

## 阅读与编辑

文字资料复用正文编辑器的 HTML 白名单、段落转换、粗体/斜体/下划线、标题/引用/列表和编辑样式；有独立保存接口，资料编辑不会写入章节。输入后自动保存，也可点击「保存」或 Ctrl/Cmd S；切换文件、分区、小说与离开页面前先保存。输入法组字完成前不保存、不切换。保存失败保留当前编辑区，并提供下载编辑稿的入口。

编辑稿保存在数据库，原上传文件保持不变。Word/PDF 的编辑针对提取出来的文字，不回写原生文件排版。「下载」分别提供上传原件、服务器已保存的文字稿 TXT 和当前编辑稿 TXT。搜索和 Agent 分页读取使用当前保存文字。

浏览器本地草稿用于刷新恢复；本地存储不可用时会提示，不替代服务器备份。版本冲突不会覆盖服务器最新稿；先下载需要的本地稿，再明确选择读取最新版本（会放弃当前未保存稿）。这不是完整的编辑历史版本功能。

「管理」可改名或手动移动；「移入回收站」保留原件，误删可恢复。非空目录（包含回收站文件）不能删除。上传设定、人物或正文资料不会修改作品对应的数据。

## 存储与备份

默认目录为 `data/`，可通过 `NOVELSTUDIO_DATA_DIR` 指向独立数据目录：

- `novel.db`：目录、文件元数据、完整提取/编辑文字、编辑稿 HTML、版本号、回收站状态。
- `file-library/<UUID>`：完整原件，无嵌套第三方 Git。

**完整备份需同时复制数据库和 file-library 目录。** 既有「SQLite 备份」接口只备份数据库，不包含文件原件。复制运行中的数据库应使用 SQLite 备份接口获得一致快照，或停止服务后复制整个数据目录。回收站不永久清除原件。

还原升级前、不包含文件库表的旧备份时，当前文件库保留；所属作品已不在备份中的资料转为共享资料，原件和目录不丢。API 返回 `file_library_preserved=true`。包含文件库的新备份会还原其元数据；从其他机器搬迁时还需复制对应原件目录。

包含文件库、但尚无编辑稿字段的 1.22.0 备份也可还原；缺少的 HTML 为 NULL、版本号为 0，资料文字和原件仍可使用并继续编辑。

旧版资料库从文件库底部的「旧版资料导入」打开，旧登记未被静默迁移或删除。

## 只读接口

Agent 凭宿主能力令牌调用时，必须明确指定 `work_id=<ID>` 或 `scope=shared`。直接使用模型参数指定磁盘路径不受支持。

| GET 路径 | 内容 |
| --- | --- |
| `/api/files/status` | 分类计数、书夹计数与作品概况 |
| `/api/files` | 目录与文件，支持 area、folder_id、q、offset、trash=1 |
| `/api/files/:id/text` | 文本分页；offset 默认 0，limit 默认 20000，最大 50000 |
| `/api/files/:id/original` | 下载完整原件 |
| `/api/files/:id/preview` | 内容签名通过的图片预览 |
| `/api/files/:id/edit` | 完整文字、编辑稿 HTML、版本号和可编辑状态 |
| `/api/files/:id/export` | 已保存文字稿 TXT 下载 |

每条文件操作都检查归属。模型写请求返回 403。普通作者界面的目录、上传、改名、移动、回收站及恢复接口可用。作者保存编辑稿使用 `PUT /api/files/:id/content?work_id=<ID>`（共享用 `scope=shared`），请求体为 `{html,text,revision}`；返回递增版本，过期版本 409，未指定归属 400。文字与 HTML 各限 20 MB，并受通用 JSON 请求体上限约束。

文件库服务入口已可供下一步资料工具使用。本轮没有注册或运行新的资料 Agent；正式开放讨论任务前，仍须验证 dsh 的实际工具白名单，禁用该任务中的通用文件写入、编辑和 Shell。现有 dsh 通用工具不能被宣称为全局只读。拆书分析和扫榜采集也未在本轮运行。

分类参考：[Novelcrafter Codex](https://www.novelcrafter.com/features/codex)、[Campfire Research](https://www.campfirewriting.com/learn/research-tutorial)、[Zotero Collections and Tags](https://www.zotero.org/support/collections_and_tags)。分区是创作用途，子文件夹与书夹是用户手动组织；不自动猜测文件类别。
