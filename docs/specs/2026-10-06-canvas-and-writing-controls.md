# 写作交互与剧情画布

用户已确认：目录拖宽/折叠，字体和背景独立，选中空卷建章，搜索可点击关闭，书架与辅助工具精简，接入 Excalidraw 无限画布。

## 交付范围

- 写作目录按选中卷建章，卷编辑独立菜单；宽度、折叠、字体排版与背景设置独立保存。
- 首页书架突出新建、导入、继续写作；右侧常用入口为大纲、角色、设定、AI，其余收进更多。
- Excalidraw 源码归档到 third_party/excalidraw，该目录不含 .git；原始检出移到项目外保存，该本地参考目录忽略跟踪。固定版本组件与构建配置、许可证和来源记录随 Novel-King 保存。
- 每部作品一张剧情画布：文字、剧情卡、铅笔、图形、连接箭头、章节关联、工具快捷键、缩放平移和移动端操作。
- SQLite 保存完整场景和附件，版本号防止多个设备覆盖；导出可再次导入的画布文件及图片。
- AI 使用整个场景的文本与关系、作品资料和图像。建议与生成结果先预览，作者点击后才应用，支持撤销。文字模型可以使用结构信息；识图需选择支持图像的模型。

## 测试边界与顺序

1. 写作偏好与章节创建选择：独立行为单测先红后绿，浏览器验证目录与设置。
2. 画布 HTTP 接口：真实临时 SQLite / 临时服务，验证保存恢复、版本冲突、跨作品章节拒绝与删除级联。
3. AI HTTP 接口：本地假模型捕获实际请求，验证屏幕外内容、关系、图片输入和未采纳零写入。
4. 画布交互：browser-harness 验证绘制、章节链接、导入导出、刷新、手机手势与编辑器自动保存。
5. 完成前跑离线完整检查、构建、语法检查与 diff 自审。所有测试用临时数据库，不更改用户正文。
