# 多用户与算术题注册

用户确认补齐服务器账户和隔离，并指定开放注册用随机加法、乘法题。影响：新增账户网关、账户数据库、个人数据进程、登录与账号菜单、浏览器存储作用域、迁移与部署文件；本机原入口保持兼容。

1. 账户/会话/算术题/限流：HTTP 先红后绿，验证错答、重放、过期、注销、改密、停用与伪造代理头。
2. 数据隔离：每账号独立数据库和目录，使用相同作品 ID 的两个账号验证读取、修改、资料原件、画布、模型配置。检查直接访问工作进程被拒绝、主机工具封锁、私网 AI 地址拒绝。
3. 浏览器与数据迁移：单测草稿隔离、旧 SQLite WAL 快照、原件保留、重跑不覆盖；真实浏览器验证注册登录、菜单退出、移动布局；旧标签页账号切换锁定并拒绝串写。
4. 部署：新增 start:server、Docker、Caddy HTTPS、明确数据卷与备份恢复；校验 compose 配置，完成全量离线测试与 diff 自审。

算术题不是强机器人识别，不宣称绝对防批量注册；服务端一次性校验与独立注册限额配合。当前 DSH 具有主机文件操作能力，账户进程隔离不等于 OS 沙箱；服务器模式在路由及执行函数两层关闭它，后续沙箱独立接入。
