# 画布双槽快捷键设置

用户已确认这轮方案：独立入口，功能名 + 主绑定 + 备用绑定，点击录入，字母/数字/F 键/组合键/滚轮，冲突提示、清除与恢复默认，刷新保留，编辑文字时不误触。

## 范围与交互

- 顶部独立「快捷键设置」按钮，画布右下角再提供直接入口，取代静态默认快捷键帮助入口。面板显示当前配置，不把第三方默认说明当作可编辑设置。
- 每个功能两个槽位。点槽位进入等待状态，捕获下一次完整键盘按键或滚轮方向；单独按修饰键保持等待，Esc 取消录入。槽旁的清除按钮可留空。取消窗口不保存修改，点「应用」才生效。
- 功能覆盖绘图工具、剧情卡、保存、查看全图、缩放、平移、撤销/重做、删除和打开设置。正文编辑器、画布文字、AI 输入、搜索与其他窗口不接管快捷键。
- Mouse+ 表示上滚（deltaY < 0），Mouse- 表示下滚（deltaY > 0）；水平滚动显示 Mouse← / Mouse→，不当作上下滚动。支持修饰键加滚轮。默认普通滚轮平移、Ctrl 加滚轮缩放。
- 重复绑定明确指向占用功能和槽位，可选择替换；清除或改绑后，受管理功能的旧默认键不再偷偷触发。文本编辑、复制粘贴与未纳入设置的原生编辑操作保持原有行为。
- 偏好存当前浏览器，与作品/画布内容分离；迁移旧版单字母配置，保留用户旧绑定。面板沿用全局配色，手机三列紧凑排布且纵向滚动，按钮可触控。

## 实施与验证

1. 公共绑定模块：先红后绿验证双槽、旧配置迁移、清除、冲突、组合键、滚轮方向、IME 与修饰键。
2. 独立面板与事件路由：先以浏览器确认入口/双槽不存在，再实现按键录入、取消/应用、重置和真实功能触发。
3. 真实浏览器验证改绑后的工具、缩放/平移、旧键失效、保存、撤销/重做、文字输入保护、刷新恢复、桌面/390px 手机布局，查看截图。
4. 构建本地画布资产，完整离线测试、语法检查、diff 自审。测试只写隔离数据库，不修改作者正文或画布。

## 已确认的缺陷

旧版输入框即时规范化：删除当前值后会恢复原键，并提示「请输入一个未占用的英文字母」，普通删除再输入无法完成改绑。只支持七个工具各一个字母；第三方帮助窗口是只读默认列表。新方案改为明确的捕获状态与应用边界。

## 实现与验证记录

- 配置模块改为 26 个功能、每个两个槽位；旧单字母配置自动读取为主键。空槽持久化，录入采用物理按键编号，数字与 Numpad 数字分开。
- 设置窗口通过 portal 挂载在页面顶层，沿用全局外观，包含焦点回环、关闭后恢复焦点、冲突替换和存储失败提示。过长组合键截断显示，悬停可查看完整绑定。
- 事件只接管活动画布，文字编辑、输入法、AI 输入和其他界面不接管。撤销/重做复用原生历史按钮，删除转发到原生键盘处理，避免直接删除元素破坏连线与撤销记录。平移与缩放不会写入元素历史。
- 公共模块四条测试分别先红后绿；浏览器先确认独立入口不存在，再验证新交互。另以真实按键复现旧 Shift+= 与 Numpad 数字仍触发的问题，修正后通过。
- `scripts/ui-shortcuts-acceptance.py` 在隔离 HTTP/SQLite 实例上使用 browser-harness/CDP 的真实键盘、鼠标和滚轮事件：双槽、主/备用工具切换、旧键失效、冲突取消/替换、组合键、上下/水平滚轮、删除/撤销/重做/保存、画布文字与 AI 输入保护、Esc、刷新、清空及默认配置取消/应用。
- 桌面 1440×900 与手机 390×844 截图人工检查，窗口三列没有横向溢出。截图保存到系统临时目录 `novel-king-shortcut-review/shortcuts-desktop.png` 与 `shortcuts-mobile.png`。
- 菜单、多种外观、系统模式、自定义强调色、背景文件选择/拖入/取消/非法文件与手机面板回归通过。手机回归首次点击因布局未稳定未打开窗口，等待布局稳定后重新执行该段通过。
- 完整离线检查共 56 组，构建、JS 语法和 diff 检查通过。项目没有单独的 TypeScript/lint 脚本；JSX 由 esbuild 构建验证。测试使用隔离数据库，真实预览继续运行在 3740。

偏好属于当前浏览器，不随服务器账号跨设备同步。复制/粘贴、空格拖动等未列入面板的原生编辑与鼠标手势继续沿用原画布行为；已列入面板的旧默认按键及缩放/数字别名被拦截，不能绕过配置。
