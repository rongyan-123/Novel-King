# Novel-King 写作工作台

用户已确认：参照提供的作家助手截图，创建即写作；固定顶部工具栏、左侧卷章目录、右侧功能栏和底部状态栏，只有正文滚动。移动端目录和参考工具使用抽屉。

## 范围与数据

- 新建作品直接创建未命名作品及第1章，名称可后改。简介、目标字数、结构等保留在作品设置。新建章节直接打开空稿。
- 富文本继续以 HTML 存入现有 SQLite；纯文本复制和 TXT 导出保留段落，显示偏好不进入正文。
- 顶部提供字体、字号、行距、正文宽度、边距、背景，撤销重做、排版、查找、保存、历史、复制和导出。
- 右侧入口复用大纲、角色、设定、AI 与故事状态功能；参考面板可收起，不重建正在输入的编辑器。
- 默认深蓝工作台，可切换纸色或护眼色、上传背景图。设备偏好存浏览器；作品仍存服务器数据库。
- 创建作品及初始章节使用现有事务，一次成功或全部回滚；快速重复点击复用进行中的请求。

## 验证

先写偏好、创建请求去重与失败恢复、发布文本及查找的测试并跑红；实现后跑绿。通过隔离 HTTP 实例验证作品/章节原子创建和旧创建接口兼容。

browser-harness 在独立数据库中验证桌面长章、手机抽屉、中文输入、切章保存、刷新恢复、复制、偏好与滚动边界。运行完整离线检查和 JavaScript 语法检查，自审 diff。测试不使用作者数据库或计费模型。

## 完成验证

- 9 个新增行为用例通过；创建接口故障注入证明作品和首章同时回滚。
- 完整离线检查 52/52 通过；JavaScript 语法检查、diff 空白检查通过。项目没有配置独立 TypeScript 或 lint 命令。
- browser-harness 实测 1440×900：工作台 scrollHeight/clientHeight 均为 900；13,000 多字正文独立滚动，工具栏固定。
- 390×844 及键盘压缩后的 390×480 视口无外层滚动；目录与参考抽屉开关正常。
- CDP 中文组合输入暂停保存，提交后恢复；切章及刷新后正文不丢。已验证剪贴板纯文本、段落换行、就地改名、字号/主题恢复、编辑节点保留、排版撤销重做与历史版本入口。
- 原数据库已通过应用整库备份，完整性为 ok；启动新版前后现有作品与正文的 SHA-256 指纹相同。
- 自动审批拒绝关闭旧服务并重启的组合命令（blocked by policy）。旧服务保留，新版在 http://localhost:3739 使用原数据库运行。浏览器测试使用独立数据库、独立端口 38467。
