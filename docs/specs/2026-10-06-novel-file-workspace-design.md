# 小说资料工作台

用户已确认「小说 → 资料分区 → 文件夹」结构，并追加左侧切换资料、右侧复用正文编辑器、空目录默认上传的要求。

## 范围与行为

- 文件库首页用小说卡片和独立共享卡片代替默认全部资料。小说卡片显示本书文件、人物、设定与最近章节；不自动推断旧文件归属。
- 进入小说后展示原有十个分区。分区内左侧切换分区、文件夹和文件，右侧自动打开当前目录首个文件；空目录展示上传入口。上传按钮常驻左侧。
- 文本文件、Word/PDF 提取正文可直接编辑。图片保留预览，未能提取的其他格式可下载原件。正文编辑器的 HTML 白名单、段落转换、格式工具与 CSS 复用，资料保存独立于章节保存。
- 原件保持不变；SQLite 保存编辑稿 HTML 与当前可检索文字。下载提供原件及当前文字稿，明确区分。上传 Word/PDF 后的编辑保存为资料编辑稿，不声称能回写其原生排版。
- 保存携带版本号，冲突返回 409，避免其他窗口的更新被覆盖。切换文件/分类/小说/离开工作台前先保存；失败保留编辑区。编辑时留本地草稿，刷新可以恢复，输入法组字结束后再保存。
- 仅在选定小说或共享范围内上传、检索、管理、阅读和编辑。Agent 仍只有限定范围的 GET，无资料编辑权限。本轮不增加 AI 任务或爬虫。

## 步骤与验证（沿用已确认的公共接口与浏览器验收边界）

1. 接口测试先红后绿：小说卡片数量隔离、编辑稿持久化与原件不变、版本冲突、跨小说拒绝与 Agent 写入拒绝。
2. 浏览器验收先证明旧页面没有小说卡片与嵌入编辑器，再实现小说入口与资料工作台。原生点击验证左侧切换、空目录上传、编辑保存/格式保留/刷新、移动归属与手机布局。
3. 全部离线检查、语法检查、自审 diff；用独立数据目录验收，保持现有作品正文数据不变。
