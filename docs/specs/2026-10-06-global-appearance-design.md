# 全局外观与画布菜单修复

用户已确认：修复画布菜单崩溃；全局配色覆盖书架、正文、画布工具与弹窗；小说背景只上传图片，支持拖入；统一设置面板。补充授权：提供可切换的极简、冷峻、质感、卡通风格。

## 设计

右上角统一「外观」入口，正文与画布也始终可访问。浅色、深色、跟随系统与四种风格独立选择，支持自定义强调色。全局偏好存浏览器，刷新与跨页面保持一致；切换不重建编辑器、不修改正文或图形。绘图背景颜色属于场景数据，不因切换主题重写。

基础配色：浅色底 #F3F5F7、面板 #FFFFFF、正文 #263244、边框 #DDE3EB、强调色 #3D73C8；深色底 #1C2430、面板 #263140、正文 #E6EDF5、边框 #3B485B、强调色 #3D73C8（文字链接在深色中提高亮度）。极简强调留白与细边框；冷峻采用紧凑直线、蓝灰强调；质感采用柔和层次与细致阴影；卡通采用较圆的角、明确边线与小幅错位阴影。主题色可以覆盖风格默认强调色，深浅背景仍保持可读性。

使用设备现有中文 UI 字体，常规控件 14px、面板标题 18px、辅助信息 12px；8px 间距尺度。对齐为标签在上、控件在下，相关设置按用途分组；手机保持双列风格卡、内容可纵向滚动，主要触控目标至少 44px。不新增装饰动画或营销区块。

小说背景窗口：宽幅拖入区 → 图片预览与文件名称 → 显示强度 → 横向网格。移除旧配色和自定义底色，上传与拖入共用大小/格式校验。取消保留原背景；更换前验证新文件；失败就地提示。字体窗口按字体、字号、行距、正文宽度和段落规则重排。

## 顺序与验收边界

1. browser-harness 原生点击菜单：先确认崩溃，再修复不存在的菜单项，反复打开/关闭后继续绘图。
2. 全局外观偏好公共函数：先红后绿验证非法值、持久化、旧 ns_theme 迁移、跟随系统；浏览器验证切换保留编辑节点和画布。
3. 背景公共校验与偏好合并：先红后绿验证撤销旧配色写入、合法图片和大小边界；浏览器验证拖入、取消、替换和刷新。
4. browser-harness 桌面/手机截取四款风格、深浅主题、外观与上传窗口，检查可读性、对齐、触控和滚动。
5. 完整离线检查、画布构建、语法检查、diff 自审；测试仅用临时数据库。保留原稿与已有画布数据。
