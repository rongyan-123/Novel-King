# Novel-King 剧情画布

进入作品写作台，顶部「正文 / 大纲画布」切换两种工作方式。左侧仍是章节目录；选中卷后新建章节会进入该卷，卷的修改与删除在独立的「⋯」菜单中。电脑可拖动目录右边缘调整宽度，手机点击「目录」打开抽屉。

## 画大纲

- 点「＋ 剧情卡」添加卡片，双击文字修改内容。原生工具栏提供文字、图形、铅笔、箭头与橡皮。
- 「关联章节」将选中的卡片或图形关联到当前作品的章节，再点「打开章节」回到正文。
- 电脑按住空格拖动平移，手机双指缩放；「查看全图」让所有剧情重新进入视野。
- 「快捷键」可替换工具的单字母快捷键。输入文字时不触发工具快捷键，重复的按键不会覆盖其他工具。
- 操作可通过画布内的撤销按钮或聚焦画布后的 Ctrl / Cmd + Z 撤销。

## 保存与导出

每部作品有一张独立画布，完整场景、视口与图片保存在服务端 SQLite 的 `work_canvases` 表中。自动保存与正文保存分开，Ctrl / Cmd + S 在画布中保存画布。

多页面或多设备发生版本冲突时，服务器拒绝覆盖。先点「导出」保存本机版本，再「重新载入」获取服务器内容。

「导入 / 导出」提供可重新导入的 `.excalidraw` 文件与整图 PNG。导入前验证格式与章节归属，然后明确确认替换；导入后可立即撤销。当前单图限 5000 个元素、12 MB 附件及场景数据。

## AI 剧情助手

在「AI 设置」配置 OpenAI 兼容接口，再打开画布上的「AI 剧情助手」。填写要求，选择「给我建议」或「生成剧情图」。

AI 收到整张画布的文字、图形和箭头关系，包括屏幕外元素，并收到当前作品的章节正文、角色、设定、世界观与故事记忆。画布上的计划明确作为候选剧情，不当成已发生的事实。

勾选「识图」会同时发送完整画布的 PNG，需要选择支持图片输入的模型。未勾选时通过结构数据理解文字与关系。

建议先显示在面板中。点击「加入画布（可撤销）」才添加剧情卡和箭头；正文与设定不会自动改写。生成后若画布已改变，需要重新生成。资料超过 40 万字符时会明确拒绝，不静默截断；实际可用长度还取决于模型的上下文限制。

## 构建

仓库包含运行资产，`npm start` 可以直接启动。修改画布源码后执行：

```powershell
npm ci
npm run build:canvas
npm start
```

入口为 `canvas/workspace.jsx`，原写作台仍在 `public/app.js`。本地参考源码 `third_party/excalidraw` 不参与构建，也不包含嵌套 Git 仓库；来源、字体及依赖许可证见 `THIRD-PARTY-NOTICES.md` 与 `licenses/`。
